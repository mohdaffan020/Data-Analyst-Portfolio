In this section I have listed the projects I have completed while learning Data Analytics. Each project focuses on solving a business problem using different analytics tools.

## Decathlon Sales & Customer Analytics

**Goal:** Analyze retail sales data to understand customer purchasing behavior, product performance, and overall sales trends.

**Repository:** [Decathlon Sales & Customer Analytics](https://github.com/mohdaffan020/Decathlon-Sales-and-Customer-Analytics-Excel.git)

**Description:** This project analyzes transactional sales data from a retail business. The analysis includes data cleaning, sales trend analysis, customer segmentation, KPI creation, and the development of an interactive Excel dashboard for business reporting.

**Skills:** Data Cleaning, Excel Functions, Pivot Tables, Power Query, XLOOKUP, Dashboard Design, Business Analysis

**Technology:** Microsoft Excel

**Results:** The dashboard provides insights into revenue trends, customer segments, product category performance, and monthly sales, helping support business decision-making.

---

## E-Commerce Cart Abandonment Analytics

**Goal:** Identify where customers leave the purchase journey and analyze factors contributing to cart abandonment.

**Repository:** [E-Commerce Cart Abandonment Analytics](https://github.com/mohdaffan020/E-Commerece_Cart_Abandonment_Analysis_PowerBI.git)

**Description:** This project explores customer behavior throughout the online purchase funnel. Interactive Power BI dashboards were created to analyze abandonment rates across devices, traffic sources, and product categories.

**Skills:** Data Modeling, DAX, Power Query, Dashboard Design, KPI Development

**Technology:** Power BI

**Results:** The analysis highlights major drop-off points in the customer journey and provides insights that can help improve conversion rates.

## Netflix Content Analysis

**Goal:** Explore Netflix's content library and answer business questions using SQL.

**Repository:** [Netflix Content Analysis](https://github.com/mohdaffan020/netflix-sql-project.git)

**Description:** This project uses SQL queries to analyze movies and TV shows available on Netflix. The analysis focuses on content distribution, release trends, country-wise production, ratings, and genre popularity.

**Skills:** SQL Queries, CTEs, Window Functions, Aggregate Functions, Data Exploration

**Technology:** PostgreSQL

**Results:** The project answers business questions related to Netflix's content catalog and demonstrates practical SQL problem-solving.
